# Alert

화면 위쪽이나 패널 안에서 지금 처리할 일을 한 문장 제목과 짧은 설명으로 알린다.

- **tone**: `critical`(연체, 적자, 사고) · `attention`(검토 후보, 기한 임박) · `progress`(대기 중인 요청) · `positive`(정산 확정 같은 결과).
- **title**은 무엇이 몇 건인지, 본문은 무엇을 해야 하는지 쓴다. **action** `{label, href}`로 해당 원장·행사로 보낸다.
- 아이콘과 왼쪽 색 띠를 쓰지 않는다. 한 화면에 같은 tone의 알림을 여러 개 쌓지 말고 한 문장으로 묶는다.
