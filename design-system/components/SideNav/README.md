# SideNav

관리자 웹 왼쪽의 주 메뉴이며, 업무 문서의 모듈(현황, 운영, 회계, 기준정보, 관리)을 그대로 따른다.

- **active**: 현재 메뉴 id. **links**: `{id: href}`. **counts**: `{id: n}` 또는 `{id: {n, tone}}`로 처리할 건수를 붙인다(클레임은 `critical`, 비용 승인 대기는 `attention`).
- **org**: 운영회사(예: "ABT 한국·몽골 통합"). **user**: `{name, role}`. **logout**: 로그아웃 링크 주소.
- **theme** / **onThemeChange**: 넘기면 사용자 줄 위에 `화면 다크·라이트` 전환이 생긴다. 선택은 화면을 옮겨도 유지되도록 화면 쪽에서 저장한다(브라우저 저장소, 실패하면 기본값 다크).
- 메뉴 아이콘은 이 시스템에서 아이콘을 쓰는 몇 안 되는 자리다. 역할에 따라 보이지 않는 메뉴는 **sections**를 줄여 넘긴다.
