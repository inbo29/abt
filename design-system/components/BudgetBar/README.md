# BudgetBar

항목별 예산(점선 틀)과 실제 지출(무채색 막대)을 한 줄에 겹쳐 보여주고, 예산을 넘은 부분만 주의·위험 색으로 칠한다.

- **budget**, **actual**, **currency**, **label**을 넘긴다.
- **warnAt**(기본 1.0)을 넘으면 `attention`, **critAt**(기본 1.1) 이상이면 `critical`이다. 기준값은 관리자가 정하는 정책이므로 화면마다 넘겨준다.
- **size**: `md`(라벨, 금액, 잔여·초과 금액 포함) · `sm`(표 칸 안, 막대와 % 만).
- 막대 하나가 비용 항목 하나다. 여러 항목을 한 막대에 쌓지 않는다.
