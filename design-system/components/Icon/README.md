# Icon

메뉴에 쓰는 Lucide 선 아이콘(1.75)이며, 버튼·배지·알림·표에는 쓰지 않는다.

- **name**: `layout-dashboard`, `bell`, `file-spreadsheet`, `calendar-days`, `calendar-range`, `clipboard-check`, `message-square-warning`, `wallet`, `receipt`, `send`, `arrow-left-right`, `scale`, `building-2`, `package`, `hotel`, `users`, `book-open`, `user-cog`, `history`, `house`, `plus`, 그리고 기능 표시용 `chevron-*`, `chevrons-up-down`, `x`, `menu`, `check`.
- **size**: 메뉴 18, 모바일 탭 22. 색은 글자색을 따른다. **title**을 주면 이름을 읽어 주고, 없으면 장식으로 숨긴다.
