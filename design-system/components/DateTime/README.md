# DateTime

날짜와 시각을 "10.03(토) 07:30 ULAT" 형식으로 쓰고, 필요하면 다른 시간대의 시각을 함께 보여준다.

- **value**는 그 시간대의 현지 시각 "2026-10-03T07:30"이고 **zone**은 `ULAT`(몽골, UTC+8) 또는 `KST`(한국, UTC+9)다.
- **format**: `datetime`(기본) · `date`("2026.10.03 (토)") · `short`("10.03(토)") · `time`.
- **other**를 켜면 다른 시간대 시각을 붙인다("08:30 KST"). 현장 기록은 ULAT, 본사 처리 기록은 KST로 남긴다.
