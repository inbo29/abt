# Button

화면의 행동을 실행하는 버튼이며, 주 버튼(`primary`)은 무채색 `action` 채움으로 화면당 하나만 둔다.

- **variant**: `primary`(주 행동: 승인, 제출, 송금 요청) · `secondary`(기본) · `ghost`(취소, 필터 초기화) · `danger`(반려, 삭제처럼 되돌리기 어려운 행동, `critical` 채움).
- **size**: `sm`(필터 줄, 표 안) · `md`(관리자 웹 기본, `control-md`) · `lg`(가이드 모바일, `control-lg`).
- **href**를 주면 `<a>`로 그린다(화면 이동). **block**은 폭을 채운다(모바일 하단 행동).
- 글자는 행동 이름으로 쓴다: "송금 요청", "승인", "반려". "확인", "제출하기" 같은 모호한 말은 피한다.
- 아이콘을 넣지 않는다. 상태색은 `danger` 하나만 쓴다.
